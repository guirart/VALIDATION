# Veredicta v3.10.1 — Auth confirmation fix

- Corrige o parse da resposta REST do Supabase `/auth/v1/signup`: com confirmação de e-mail ativa, o usuário pode vir no nível raiz do JSON.
- O redirect de confirmação e recuperação usa a origem real da requisição quando disponível, evitando depender exclusivamente de `APP_BASE_URL`.
- Login repara automaticamente perfil Veredicta ausente quando o usuário já existe e autentica no Supabase.
- O Supabase ainda precisa ter a URL de produção em Authentication > URL Configuration > Site URL e Redirect URLs.
- Validator jurídico permanece em 3.8.1.
