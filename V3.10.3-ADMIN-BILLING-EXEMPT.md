# VEREDICTA v3.10.3 — ADMIN BILLING EXEMPT

Esta versão adiciona isenção de cobrança para a conta administrativa.

## Configuração

Na Vercel, defina:

`VEREDICTA_ADMIN_EMAIL=seu-email-de-admin@dominio.com`

A conta ainda precisa existir no Supabase Auth e usar e-mail/senha válidos. A isenção de pagamento não desativa autenticação.

## Comportamento

- O e-mail configurado em `VEREDICTA_ADMIN_EMAIL` é promovido automaticamente para `role=admin` no próximo login.
- O perfil administrativo recebe `status=active` e `subscription_status=admin_exempt`.
- O administrador entra no app sem Stripe, mesmo sem assinatura.
- Usuários comuns continuam exigindo assinatura `active` ou `trialing`.
- Se a conta administrativa for cadastrada depois da configuração, o cadastro não abre Checkout Stripe.
- Chaves GPT pertencentes a um usuário `admin` também não exigem assinatura.
- A autenticação por senha do Supabase continua obrigatória para o painel web.
