# VEREDICTA v3.10.2 — PAYMENT REDIRECT FIX

Correções:

1. Corrige criação de Stripe Checkout para novos clientes: `customer_update` só é enviado quando já existe `customer`.
2. No login, usuário sem assinatura ativa é redirecionado automaticamente para a URL de pagamento quando ela puder ser criada.
3. Estados `pending`, `incomplete`, `incomplete_expired` e `canceled` geram novo Checkout; `past_due`/`unpaid` com Customer existente usam Billing Portal.
4. Se a Stripe rejeitar a criação da cobrança, a tela mostra o motivo seguro retornado pelo backend em vez de apenas a mensagem genérica de inadimplência.
5. Não altera o validator jurídico 3.8.1 nem a taxonomia dos 15 pontos.
