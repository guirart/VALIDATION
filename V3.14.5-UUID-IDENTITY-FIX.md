# Veredicta 3.14.5 — identidade canônica por UUID

## Correção

A identificação de casos deixou de usar `title` como fallback na importação sintética.

- `cases.id` (UUID) é a identidade canônica interna.
- `external_test_id` é a chave estável/idempotente apenas para datasets sintéticos.
- `title`, `client_name`, nomes das partes e `contract_text` não são usados para deduplicar, adotar, localizar histórico ou associar análises.
- Casos com títulos ou nomes idênticos permanecem independentes quando têm UUIDs diferentes.
- A listagem e a busca MCP agora expõem `external_test_id`, `synthetic` e `environment` junto ao UUID para diagnóstico de testes.

## Compatibilidade

A compatibilidade com casos sintéticos legados sem `owner_id` permanece, mas somente quando o mesmo `external_test_id` identifica o registro órfão. Nenhuma adoção por título/nome é realizada.
