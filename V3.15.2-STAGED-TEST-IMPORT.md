# Veredicta 3.15.2 — Staged Test Import

A importação de lotes sintéticos agora pode ser fracionada para reduzir o payload de cada chamada e permitir retomada segura quando uma chamada é interrompida antes de alcançar o backend.

## Fluxo recomendado

1. `iniciar_importacao_lote_veredicta` — envia apenas `environment=test`, `batch_id` e `expected_total`.
2. `importar_caso_lote_veredicta` — envia exatamente um caso por chamada e recebe o `case_id` UUID.
3. `finalizar_importacao_lote_veredicta` — confere os `external_test_id` únicos processados e conclui somente quando a contagem atinge `expected_total`.

A idempotência de entrada continua baseada em `external_test_id`. Depois da criação, a identidade canônica é exclusivamente `case_id` UUID. `title`, `client_name`, nomes das partes e texto contratual nunca são chaves de associação.

O endpoint legado `/api/gpt/test-import` permanece disponível para compatibilidade. Os novos endpoints são funções Vercel independentes: `/api/gpt-test-import-start`, `/api/gpt-test-import-case` e `/api/gpt-test-import-finalize`.
