# Veredicta 3.14.3 — fontes no status existente

Para contornar cache do catálogo MCP, `consultar_status_veredicta` agora inclui os textos integrais já na propriedade `sources`.

O fluxo não depende mais da descoberta de uma ferramenta nova:

1. chamar `consultar_status_veredicta`;
2. conferir os hashes externos e internos;
3. usar `sources.legal_source.content` para `mp_quote`;
4. usar `sources.memorandum.content` para orientar os 15 pontos;
5. interromper sem enviar se conteúdo ou hashes estiverem ausentes ou divergentes.

`consultar_fontes_juridicas_veredicta` continua disponível como alternativa para clientes que já descobriram a ferramenta.
